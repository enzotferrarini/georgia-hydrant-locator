Dependencies are pinned; pytest is development-only. No paid API or secret is required.

Resource safeguards include a 300-character input limit, 10-mile maximum radius, 10,000 source records, 200-record batches, 250 displayed/downloaded candidates, 8 MB response limit, 15-second per-request timeout, two attempts, and a batch deadline checked between requests. Two searches/eight HTTP requests can run concurrently per process. Separate five-second per-session cooldowns discourage repeated address lookups, hydrant searches and map corrections without delaying movement between these steps. Blocked repeat clicks preserve the current match and result. New sessions or multiple worker processes can bypass that cooldown; this is not a full abuse-prevention service.

Addresses go to Census; Barrow house numbers go to county GIS for exact-match selection. Corrected coordinates go to Census for county validation; search envelopes go to configured GIS publishers. The browser requests OpenStreetMap tiles. Hosting and these third parties may retain operational/request logs outside this application's control. The website and repository are public; users must follow their organization's policy for customer information. Public GIS access does not certify redistribution rights, inventory completeness, field accuracy or operational status.

The app now includes a dated public Gwinnett hydrant backup (record IDs, coordinates and update dates only). This persistent public-source snapshot contains no user searches. Its weekly refresh workflow has repository contents-write permission solely to commit validated snapshot updates on main. Last-good data is retained when refresh fails.
